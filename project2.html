Documentation Car Parking Management System (GUI)

Below are the screenshots and interface breakdowns of the Car Parking Management System (GUI):

1. Main Dashboard & Interactive Slot Grid

The primary user interface featuring a 55-slot interactive parking grid with real-time status indicators (Green = Available, Red = Occupied). It includes vehicle registration input (W 2436 AW), slot allocation display, and navigation buttons (Enter, Exit, and History).

2. Vehicle Exit & Billing Dialog

A pop-up notification window triggered during vehicle checkout. It automatically calculates and displays the license plate, slot number, exact entry/exit timestamps, and total parking fee.

3. Activity History & Transaction Log

A structured log file recording full transaction records for both vehicle entry and exit events, detailing license plates, assigned slots, timestamps, and payment statuses.

Detailed System Workflow & Implementation Methodology

In developing this parking management system, the process began with designing a structured parking slot management logic using a 2D matrix-based data representation. Each parking slot was initialized and monitored in real time to determine its availability status, where 0 represents an available slot and 1 represents an occupied slot.

The vehicle entry process was designed with an automated slot allocation mechanism. When a vehicle enters the system, the license plate information is recorded, and the application searches for the first available parking slot. The system then updates the slot status and stores the entry timestamp for further transaction processing.

During the exit process, the system captures the checkout timestamp and calculates the total parking duration based on the difference between entry and exit times. A billing algorithm is applied to generate the parking fee automatically, while the occupied slot is released and returned to an available state.

All parking transactions are stored in a structured history log containing vehicle license information, transaction status, timestamps, assigned parking slots, and calculated fees. This approach ensures accurate data management, real-time monitoring, and efficient parking operations through an automated system workflow.

A Personal Note

This project demonstrates how programming logic and data management can be combined to create an automated parking management system. By implementing real-time monitoring, automated slot allocation, and transaction tracking, the system provides an efficient solution for managing parking operations.
